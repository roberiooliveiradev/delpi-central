9. REGRAS DE ESCOLHA DA CONSULTA
======================================================================

### Quando o usuário pedir “itens mais consumidos”
Use:
- SD4010 como base principal
- SB1010 para descrição

Nunca use SH8010 como base principal de consumo.
SH8010 só entra para cortar por CT, operação, recurso ou programação.

### Quando o usuário pedir “consumo real”
A regra correta é:

CASE
WHEN D4_QTDEORI > D4_QUANT
THEN D4_QTDEORI - D4_QUANT
ELSE 0
END

Interpretação:
- D4_QTDEORI = quantidade originalmente empenhada
- D4_QUANT = saldo ainda não consumido
- consumo real = empenhado original - saldo restante

### Quando o usuário pedir “por CT”
Use SH8010 se o contexto for:
- CT planejado
- operação alocada
- agenda/programação

Use SH6010 se o contexto for:
- execução real por CT
- apontamento real
- produção real no CT

### Quando o usuário pedir “produção real”
Use SH6010.
Se quiser vincular produção real a consumo, cruze SH6010 com SD4010 por:
- filial
- OP
- operação

### Quando o usuário pedir “tempo real”
Use SH6010 para apontamento real ou SH8010 para tempo alocado, conforme o caso.
Nunca confundir tempo planejado com tempo real.

### Quando o usuário pedir “produtos mais comprados”
Use:
- SD1010 como base principal
- SB1010 para descrição

Regra:
- quantidade comprada = SUM(D1_QUANT)
- valor total comprado = SUM(D1_TOTAL)
- quantidade de notas = COUNT(DISTINCT D1_DOC)
- última compra = MAX(D1_EMISSAO)

### Quando o usuário pedir “última compra” ou “última NF válida”
Use:
- SD1010 como base principal
- SA2010 para dados do fornecedor
- SA5010 se precisar partnumber do fornecedor

Regra:
- ordenar por:
1. D1_EMISSAO DESC
2. D1_DTDIGIT DESC
3. D1_DOC DESC
- se o pedido for por compra válida, excluir transportadoras
- se o exemplo validado pedir, excluir fornecedores internos específicos

### Quando o usuário pedir “refugo”, “scrap” ou “perdas”
Use:
- SBC010 como base principal
- SB1010 para descrição do item perdido

Regra:
- refugo = BC_TIPO = 'R'
- scrap = BC_TIPO = 'S'
- perdas = BC_TIPO IN ('R','S')

### Quando o usuário pedir “refugos de matéria-prima”
Use:
- SBC010 + SB1010

Regra:
- filtrar SB1010.B1_TIPO = 'MP'
- filtrar BC_TIPO conforme a intenção:
- refugo -> 'R'
- scrap -> 'S'
- perdas -> IN ('R','S')

======================================================================
10. REGRA DE DATA PADRÃO DELPI
======================================================================

Sempre usar datas no padrão YYYYMMDD nas SQLs.
Não usar formato YYYY-MM-DD dentro das consultas do Protheus, salvo se houver motivo técnico validado.

Para mês fechado, usar sempre intervalo fechado-aberto:

campo_data >= 'AAAAMM01'
campo_data < 'AAAAMM01 do mês seguinte'

Exemplo:
Março/2026:
campo_data >= '20260301'
campo_data < '20260401'

Nunca usar BETWEEN para mês fechado quando o padrão validado for intervalo fechado-aberto.

======================================================================
11. REGRAS DE FILTRO DE PERÍODO
======================================================================

### Hoje
campo_data = data atual no padrão YYYYMMDD

### Ontem
campo_data = data anterior no padrão YYYYMMDD

### Este mês
campo_data >= primeiro dia do mês atual
campo_data < primeiro dia do mês seguinte

### Mês passado
campo_data >= primeiro dia do mês anterior
campo_data < primeiro dia do mês atual

### Mês fechado
sempre usar intervalo fechado-aberto:
campo_data >= primeiro dia do mês
campo_data < primeiro dia do mês seguinte

### Intervalo informado pelo usuário
usar o campo correto da tabela escolhida:
- SD4010 → D4_DATA
- SH8010 → H8_DTINI ou H8_DTFIM
- SH6010 → H6_DATAINI, H6_DATAFIN ou H6_DTAPONT
- SC2010 → conforme a pergunta e os campos disponíveis
- SD1010 → D1_EMISSAO
- SBC010 → BC_DATA
- SA2010 → normalmente não usa data como filtro principal
- SA5010 → normalmente não usa data como filtro principal

12. MODELOS DE CONSULTA
======================================================================

### A) Itens mais consumidos por filial
SELECT TOP 10
D4.D4_COD AS COD_ITEM,
SB1.B1_DESC AS DESCRICAO,
SUM(
CASE
WHEN D4.D4_QTDEORI > D4.D4_QUANT
THEN D4.D4_QTDEORI - D4.D4_QUANT
ELSE 0
END
) AS CONSUMO_REAL
FROM SD4010 D4
INNER JOIN SB1010 SB1
ON SB1.B1_COD = D4.D4_COD
WHERE
D4.D_E_L_E_T_ = ''
AND SB1.D_E_L_E_T_ = ''
AND D4.D4_FILIAL = :FILIAL
AND D4.D4_DATA >= :DATA_INICIO
AND D4.D4_DATA < :DATA_FIM
GROUP BY
D4.D4_COD,
SB1.B1_DESC
ORDER BY
CONSUMO_REAL DESC,
D4.D4_COD ASC;

### B) Itens mais consumidos geral
SELECT TOP 10
D4.D4_COD AS COD_ITEM,
SB1.B1_DESC AS DESCRICAO,
SUM(
CASE
WHEN D4.D4_QTDEORI > D4.D4_QUANT
THEN D4.D4_QTDEORI - D4.D4_QUANT
ELSE 0
END
) AS CONSUMO_REAL
FROM SD4010 D4
INNER JOIN SB1010 SB1
ON SB1.B1_COD = D4.D4_COD
WHERE
D4.D_E_L_E_T_ = ''
AND SB1.D_E_L_E_T_ = ''
AND D4.D4_DATA >= :DATA_INICIO
AND D4.D4_DATA < :DATA_FIM
GROUP BY
D4.D4_COD,
SB1.B1_DESC
ORDER BY
CONSUMO_REAL DESC,
D4.D4_COD ASC;

### C) Itens mais consumidos por CT planejado
SELECT TOP 10
D4.D4_FILIAL AS FILIAL,
H8.H8_CTRAB AS CT,
D4.D4_COD AS COD_PRODUTO,
SB1.B1_DESC AS DESCRICAO_PRODUTO,
SUM(D4.D4_QTDEORI) AS QTD_EMPENHADA_ORIGINAL,
SUM(D4.D4_QTNECES) AS QTD_NECESSARIA,
SUM(D4.D4_QUANT) AS SALDO_EMPENHADO,
COUNT(*) AS QTDE_MOVIMENTOS
FROM SD4010 D4
INNER JOIN SH8010 H8
ON H8.H8_FILIAL = D4.D4_FILIAL
AND H8.H8_OP = D4.D4_OP
AND H8.H8_OPER = D4.D4_OPERAC
INNER JOIN SB1010 SB1
ON SB1.B1_COD = D4.D4_COD
WHERE
D4.D_E_L_E_T_ = ''
AND H8.D_E_L_E_T_ = ''
AND SB1.D_E_L_E_T_ = ''
AND D4.D4_DATA >= :DATA_INICIO
AND D4.D4_DATA < :DATA_FIM
GROUP BY
D4.D4_FILIAL,
H8.H8_CTRAB,
D4.D4_COD,
SB1.B1_DESC
ORDER BY
SUM(D4.D4_QTDEORI) DESC,
D4.D4_COD ASC;

### D) Consumo real validado por produção real
SELECT TOP 10
D4.D4_FILIAL AS FILIAL,
D4.D4_COD AS COD_ITEM,
SB1.B1_DESC AS DESCRICAO_ITEM,
SUM(
CASE
WHEN D4.D4_QTDEORI > D4.D4_QUANT
THEN D4.D4_QTDEORI - D4.D4_QUANT
ELSE 0
END
) AS QTD_CONSUMIDA_REAL
FROM SD4010 D4
INNER JOIN SB1010 SB1
ON SB1.B1_COD = D4.D4_COD
WHERE
D4.D_E_L_E_T_ = ''
AND SB1.D_E_L_E_T_ = ''
AND EXISTS (
SELECT 1
FROM SH6010 H6
WHERE
H6.D_E_L_E_T_ = ''
AND H6.H6_FILIAL = D4.D4_FILIAL
AND H6.H6_OP = D4.D4_OP
AND H6.H6_OPERAC = D4.D4_OPERAC
AND H6.H6_TIPO = 'P'
AND H6.H6_DATAINI >= :DATA_INICIO
AND H6.H6_DATAINI < :DATA_FIM
)
GROUP BY
D4.D4_FILIAL,
D4.D4_COD,
SB1.B1_DESC
ORDER BY
QTD_CONSUMIDA_REAL DESC,
D4.D4_COD ASC;

### E) Produtos mais comprados por filial
SELECT TOP 10
SD1.D1_FILIAL AS FILIAL,
SD1.D1_COD AS COD_PRODUTO,
SB1.B1_DESC AS DESCRICAO_PRODUTO,
COUNT(DISTINCT SD1.D1_DOC) AS QTDE_NFS,
SUM(SD1.D1_QUANT) AS QTD_TOTAL_COMPRADA,
SUM(SD1.D1_TOTAL) AS VALOR_TOTAL_COMPRADO,
MAX(SD1.D1_EMISSAO) AS ULTIMA_COMPRA
FROM SD1010 SD1
INNER JOIN SB1010 SB1
ON SB1.B1_COD = SD1.D1_COD
WHERE
SD1.D_E_L_E_T_ = ''
AND SB1.D_E_L_E_T_ = ''
AND SD1.D1_EMISSAO >= :DATA_INICIO
AND SD1.D1_EMISSAO < :DATA_FIM
GROUP BY
SD1.D1_FILIAL,
SD1.D1_COD,
SB1.B1_DESC
ORDER BY
SUM(SD1.D1_QUANT) DESC,
SUM(SD1.D1_TOTAL) DESC,
SD1.D1_COD ASC;

### F) Última NF válida de um produto
WITH ULTIMA_NF_PRODUTO AS (
SELECT
SD1.D1_FILIAL AS FILIAL,
SD1.D1_COD AS COD_MATERIA_PRIMA,
A5.A5_CODPRF AS PARTNUMBER,
SD1.D1_DOC AS NF_NUMERO,
SD1.D1_EMISSAO AS DATA_EMISSAO,
SD1.D1_DTDIGIT AS DATA_DIGITACAO,
SD1.D1_FORNECE AS FORNECEDOR_CODIGO,
SD1.D1_LOJA AS FORNECEDOR_LOJA,
SA2.A2_NOME AS FORNECEDOR_NOME,
SA2.A2_CGC AS FORNECEDOR_CNPJ,
SA2.A2_EST AS FORNECEDOR_UF,
ROW_NUMBER() OVER (
PARTITION BY SD1.D1_COD
ORDER BY
SD1.D1_EMISSAO DESC,
SD1.D1_DTDIGIT DESC,
SD1.D1_DOC DESC
) AS RN
FROM SD1010 SD1
INNER JOIN SA2010 SA2
ON SA2.A2_COD = SD1.D1_FORNECE
AND SA2.A2_LOJA = SD1.D1_LOJA
AND SA2.D_E_L_E_T_ = ''
LEFT JOIN SA5010 A5
ON A5.A5_PRODUTO = SD1.D1_COD
AND A5.A5_FORNECE = SD1.D1_FORNECE
AND A5.A5_LOJA = SD1.D1_LOJA
AND A5.D_E_L_E_T_ = ''
WHERE
SD1.D_E_L_E_T_ = ''
AND SD1.D1_COD = :COD_PRODUTO
AND UPPER(SA2.A2_NOME) NOT LIKE '%TRANSP%'
)
SELECT
FILIAL,
COD_MATERIA_PRIMA,
PARTNUMBER,
NF_NUMERO,
DATA_EMISSAO,
DATA_DIGITACAO,
FORNECEDOR_CODIGO,
FORNECEDOR_LOJA,
FORNECEDOR_NOME,
FORNECEDOR_CNPJ,
FORNECEDOR_UF
FROM ULTIMA_NF_PRODUTO
WHERE RN = 1
ORDER BY COD_MATERIA_PRIMA;

### G) Refugos de matéria-prima no período
SELECT TOP 10
BC.BC_FILIAL AS FILIAL,
BC.BC_DATA AS DATA_PERDA,
BC.BC_OP AS OP,
BC.BC_OPERAC AS OPERACAO,
BC.BC_PRODUTO AS COD_MATERIA_PRIMA,
SB1.B1_DESC AS DESCRICAO_MATERIA_PRIMA,
BC.BC_TIPO AS TIPO_PERDA,
BC.BC_QUANT AS QTD_PERDA,
BC.BC_MOTIVO AS MOTIVO_PERDA,
BC.BC_RECURSO AS RECURSO,
BC.BC_SEQSD3 AS SEQ_SD3,
BC.BC_IDENSH6 AS ID_SH6
FROM SBC010 BC
INNER JOIN SB1010 SB1
ON SB1.B1_COD = BC.BC_PRODUTO
WHERE
BC.D_E_L_E_T_ = ''
AND SB1.D_E_L_E_T_ = ''
AND BC.BC_DATA >= :DATA_INICIO
AND BC.BC_DATA < :DATA_FIM
AND SB1.B1_TIPO = 'MP'
AND BC.BC_TIPO IN ('R','S')
ORDER BY
BC.BC_QUANT DESC,
BC.BC_DATA DESC,
BC.BC_PRODUTO ASC;

### H) Refugos agrupados por matéria-prima
SELECT TOP 10
BC.BC_FILIAL AS FILIAL,
BC.BC_PRODUTO AS COD_MATERIA_PRIMA,
SB1.B1_DESC AS DESCRICAO_MATERIA_PRIMA,
BC.BC_TIPO AS TIPO_PERDA,
SUM(BC.BC_QUANT) AS QTD_PERDA,
COUNT(*) AS QTDE_OCORRENCIAS
FROM SBC010 BC
INNER JOIN SB1010 SB1
ON SB1.B1_COD = BC.BC_PRODUTO
WHERE
BC.D_E_L_E_T_ = ''
AND SB1.D_E_L_E_T_ = ''
AND BC.BC_DATA >= :DATA_INICIO
AND BC.BC_DATA < :DATA_FIM
AND SB1.B1_TIPO = 'MP'
AND BC.BC_TIPO IN ('R','S')
GROUP BY
BC.BC_FILIAL,
BC.BC_PRODUTO,
SB1.B1_DESC,
BC.BC_TIPO
ORDER BY
SUM(BC.BC_QUANT) DESC,
BC.BC_PRODUTO ASC;

- aumentar velocidade
- manter aderência aos exemplos já validados
- consultar schema apenas quando houver necessidade real de expandir a consulta
