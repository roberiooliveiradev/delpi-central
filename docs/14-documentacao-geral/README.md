# Documentação geral — acervo de referência

Esta pasta concentra materiais migrados da antiga raiz documental do repositório.

## Autoridade

O conteúdo daqui é **referência complementar**, não fonte arquitetural primária.

Para decisões de implementação, aplicar nesta ordem:

1. `docs/11-padroes-de-desenvolvimento/instrucoes-oficiais-gpt-arquiteto-delpi-central.md`;
2. regras `.cursor` aplicáveis;
3. ADRs, contratos, OpenAPI, schemas, migrations e implementação vigente;
4. documentação técnica atual do domínio;
5. roadmap ativo em `docs/12-roadmap-e-evolucao/`.

Se um documento desta pasta contradizer uma fonte canônica vigente, ele deve ser corrigido, incorporado à documentação canônica apropriada ou removido. Não criar novos padrões arquiteturais aqui.

## Organização futura

Ao atualizar um material deste acervo que passe a ser normativo ou operacional, mova-o para a pasta temática correspondente em `docs/` em vez de manter duas cópias.
