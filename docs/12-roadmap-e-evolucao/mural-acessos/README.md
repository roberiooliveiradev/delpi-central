# Mural de Acessos

Plugin para substituir vários QR Codes da fábrica por **um ou mais QRs estáveis**, cada um abrindo o menu de ícones daquele mural.

- Admin: `/apps/mural-acessos` (lista) e `/apps/mural-acessos/{id}`
- Público: `/p/mural-acessos/menu/{token}`
- API: [api-delpi/docs/api/mural-acessos.md](../../../api-delpi/docs/api/mural-acessos.md)
- Plugin: [plugins/mural-acessos/README.md](../../../plugins/mural-acessos/README.md)
