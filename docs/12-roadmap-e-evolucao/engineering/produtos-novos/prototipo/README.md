# Protótipo navegável — Produtos Novos

**Estado:** UX DEMO / PROPOSED — não implantado; nenhum dado ou API produtiva conectados.

## Abrir
Baixe ou visualize o [index.html](./index.html) em um navegador para explorar as oito telas: Visão geral, Programação de OPs, Acompanhamentos, Pendências, Histórico, Detalhes da OP, Checklist e Solicitar acompanhamento.

> Prévia de HTML diretamente no GitHub não executa scripts. Para usar a navegação, abra o arquivo localmente ou em um ambiente estático autorizado; **não publique em domínio produtivo sem aprovação**.

## Premissas e limites
- Dados, OPs, datas e métricas são exclusivamente fictícios.
- Filtros, detalhes, checklist e solicitações funcionam apenas em memória, sem persistência.
- Não contém credenciais, chamadas de rede, alterações reais, bloqueios ou publicação de desenhos.
- Não confirma existência de endpoints Carga Máquina/OP, componentes do design system ou permissões de produção.
- A execução real deve seguir os documentos 01–13 da pasta superior e a arquitetura mestra do Portal de Engenharia.
