# Lançamento de Notas Fiscais

O módulo não é mais hospedado pela `api-delpi`. A
`controllership-finance-api` é a BFF e a owner canônica das rotas, regras,
persistência e migrations de Lançamento de Notas Fiscais.

Consulte a [documentação da controllership-finance-api](../../../controllership-finance-api/README.md)
e o OpenAPI publicado pela BFF.
