# DELPI Central

Portal corporativo unificado com:

- SSO via Keycloak
- RBAC completo
- Core API governança
- Portal React Shell
- Sistema plugável via manifesto v2

## Arquitetura

- Gateway
- Keycloak
- Core API (Flask)
- PostgreSQL
- React + Vite
